# 모동중 기술 교육 OS — 갤탭 앱

이 폴더를 GitHub `class-pages` 저장소에 `dashboard/` 폴더 그대로 올리면, 갤럭시탭에서 앱처럼 설치해 쓸 수 있어요.

## 올리는 파일 (8개, 모두 같은 폴더)
| 파일 | 하는 일 |
|---|---|
| index.html | 대시보드 본체 (PC 대시보드와 같은 파일) |
| tablet.css | 갤탭 화면 배치 (가로·세로·화면 분할) |
| sw.js | 인터넷 없이도 열리게 해 주는 도우미 |
| manifest.webmanifest | 앱 이름·아이콘 정보 |
| icon-192.png, icon-512.png, icon-maskable-512.png | 앱 아이콘 |

## 갤탭에 설치하기
1. 와이파이에 연결된 상태에서 크롬으로 `https://<아이디>.github.io/class-pages/dashboard/` 열기
2. 화면이 다 뜰 때까지 기다리기 (처음 한 번만 몇 초 걸려요)
3. 화면 아래 **[앱으로 설치]**를 누르거나, 크롬 메뉴(⋮) → **앱 설치**
4. 홈 화면의 **기술 OS** 아이콘으로 열기

## 처음 한 번 설정 (⚙ 설정)
- 구글 시트 동기화 주소: PC와 같은 주소를 넣으면 PC와 같은 데이터를 써요
- 학교 정보(NEIS) 인증키
- 급식·시간표가 안 나오면: 📲 갤탭 앱 설정 → 구글 중계 주소

## 구글 캘린더를 쓰려면
Google Cloud Console → OAuth 클라이언트 → **승인된 자바스크립트 원본**에 `https://<아이디>.github.io` 추가 (뒤에 `/`나 폴더 이름 없이)

## 고친 뒤 다시 올릴 때
- index.html, tablet.css를 고치면: 그냥 올리면 돼요. 앱을 다시 열면 바뀌어요.
- sw.js를 고치면: 맨 위 `VERSION` 글자도 바꿔 주세요. 그래야 "✨ 새 버전이 있어요"가 떠요.
