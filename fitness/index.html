📲 휴대폰 앱으로 설치해 쓰기

채팅 미리보기나 휴대폰 내 파일 앱에서 직접 열면 설치 버튼이 안 떠요. 아래처럼 웹 주소(https://)로 연 뒤 홈 화면에 추가하면 진짜 앱처럼 전체 화면으로 쓸 수 있어요.

1단계 · 휴대폰만으로 주소 만들기
• 기존 깃허브 저장소가 있다면 index.html에 붙여넣고 저장 후 깃허브 주소 접속
• 없다면 운동앱.html 저장 후 tiiny.host에서 파일 선택 업로드
2단계 · 홈 화면에 앱 아이콘 추가
• 갤럭시(Chrome): 우측 상단 ⋮ → 앱 설치 또는 홈 화면에 추가
• 아이폰(Safari): 하단 공유(□↑) → 홈 화면에 추가

칼로리·탄단지·추정 1RM은 공식으로 계산한 추정치예요. 관절 체크는 자가 점검이며 진단이 아니에요. AI 코칭은 참고용이며, 통증이나 질환이 있으면 전문가와 상의하세요.
