D-1 · Test Design

테스트 방법 설계

D-17-8점서로 다른 테스트 2가지 이상, 각각 무엇을(단위)·어떻게·몇 번을 모두 구체적으로

목표 하나에 테스트 하나

내 목표 ①②③ 중 2개 이상을 골라, 서로 다른 것을 재는 테스트를 만들어요.

무엇을 · 단위까지

"잘 가나?" 대신 "이동 거리(m)", "걸린 시간(초)"처럼 숫자로 재는 것을 정해요. 눈으로 보는 것보다 정확해요.

같은 방법으로 3번

한 번은 우연일 수 있어요. 같은 출발선·같은 바닥에서 3번 재고 평균을 내요.

예시 · 목표 "3m 이상 간다" → 재는 것: 이동 거리(m) / 방법: 출발선에서 멈춘 곳까지 줄자로 잰다 / 횟수: 3번

D-2 · Results

결과 기록표와 판정

D-27-8점실제 숫자를 근거로 목표마다 달성 정도와 그렇게 판단한 까닭을 쓴다
달성 = 3회 모두 통과부분 달성 = 평균은 통과, 못 통과한 회차 있음미달성 = 평균이 통과 못함

평균은 소수 첫째 자리까지 반올림해서 비교해요. 목표 기준값과 '이상/이하'는 내 목표에 맞게 바꿀 수 있어요.

D-3 · Improvements

테스트 결과로 개선하기

D-37-8점결과를 바탕으로 개선 2가지 이상: 문제점 → 개선 방법(무엇을·어떻게) → 기대 효과
예시 1 · 문제점오른쪽으로 휘어서 2m밖에 못 감
개선 방법두 바퀴 축이 차체와 수직이 되도록 쇠자로 재어 다시 붙인다
기대 효과직선으로 달려 3m 이상 갈 수 있다
예시 2 · 문제점매끄러운 바닥에서 바퀴가 헛돎
개선 방법바퀴 둘레에 고무줄이나 미끄럼 방지 테이프를 감는다
기대 효과바닥과의 마찰력이 커져 헛돌지 않고 앞으로 나간다
